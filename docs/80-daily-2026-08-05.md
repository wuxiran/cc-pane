### 关键设计

## 2. 壁纸设置实时预览面板

### 范围

在「设置 → 壁纸」底部新增一个 120px 高的迷你预览框，实时显示当前壁纸配置在终端容器上的效果（图片/视频 fit、opacity、blur、dim、glass blur、终端底色透明度），视频按 autoplay / power-saver / focus 联动播放，BGM 与视频共享失焦/低功耗判定。

### 关键文件

- `web/components/settings/WallpaperPreview.tsx` —— 独立预览组件（与 `useThemeStore` 解耦，靠 props 接受当前配置）
- `web/components/settings/WallpaperPreview.test.tsx` —— 渲染 + 视频播放开关断言
- `web/components/settings/WallpaperSection.tsx` —— 接入：拿到 `wallpaperService.resolveWallpaperAsset` URL 后传入预览

### 关键设计

- **预览独立解析**：与工作空间无关，settings 页内自己调 `wallpaperService.resolveWallpaperAsset`，避免主题切换闪烁影响。
- **取消保护**：URL 请求带 `cancelled` flag，避免快速切换壁纸时把过期 URL 写进 state。
- **联动 5 个滑块**：opacity、blur、dim、terminalOpacity、glassBlur 全部走 props，应用层只 `update(key, v)`。
- **视频预览循环**：`playbackRate` 写入 `<video>`，autoplay + visibility + focus 三态合一决定 play/pause。

## 3. 终端路径链接对话框（OpenSpec APPROVED）

### 范围

xterm 输出里出现的项目内文件/目录路径（绝对路径、相对路径、`file://...:line:col`、OSC 8 链接）可点击 → 弹出 Radix Dialog → 4 种动作：

- 打开编辑器（自动定位 `line:column`，复用 Monaco reveal）
- 用系统默认应用打开（仅 desktop）
- 在文件管理器中显示（仅 desktop）
- 复制路径

所有路径必须经过解析+安全校验：必须在该终端 session 的项目根内、不能 `..` 越界、不能 symlink escape、不能是 SSH 远端。

### 关键文件

- `web/lib/terminalPathLink.ts` —— 纯解析器（无 IO）

- `cc-panes-core/src/services/terminal_path_link_service.rs` —— 核心解析器（带 session context）
- `cc-panes-core/src/services/terminal_backend.rs` —— `InProcessTerminalBackend` / `DaemonTerminalBackend` 注入 link context

### 关键设计

- **三层边界**：解析（纯函数，无 IO）→ 解析+授权（核心，session context 注入）→ 动作（IPC/desktop，命令层）。任何一层都不允许绕过上一层。
- **WSL 路径白名单**：仅在 `host-resolvable` 时支持，SSH 一律拒绝（SSH 没有 PTY 后端的可信 root 来源）。
- **取消对话框保护**：每个动作异步执行时 `acting` 锁 UI；`runAction` 内部 promise reject 落 toast。
- **可恢复焦点**：定位 Monaco 走 `useEditorRevealStore.request()`，即使目标文件 tab 还没打开也能在打开后定位。
- **拒绝路径类型**：项目外绝对路径、`..` 越界、symlink 跳出、unsupported scheme、socket/device/pipe、glob、虚拟文件——全部 green test 覆盖。

### 关键设计

- **优先级明确**：JSONL 观测值 > 启动时选中的 Provider 模型 > Provider 默认模型 > unknown。任何一步缺失都不能伪造回退。
- **unknown 不再伪装**：window 为 None 时，snapshot 仅保留 `usedTokens`，`windowTokens`/`usedPercentage` 都为 None，状态栏走 `-%` 分支，diagnostic 通过 `windowSource` 字段回看来源。
- **launch history modelId 兼容**：新增列使用 `serde(default)`，Tauri/REST/Web 三个入口的请求字段都是可选，旧客户端请求不会 400。
- **不外网嗅探**：不通过模型目录 API 自动发现窗口；不同供应商/代理/鉴权的接口不稳定，且会引入凭据和网络副作用。
- **不回算历史**：状态栏百分比修复只影响新查询，旧 usage 聚合表保持现状（变更范围可控）。
