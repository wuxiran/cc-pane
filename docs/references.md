- `../references/orca` — shallow clone of [stablyai/orca](https://github.com/stablyai/orca), the most direct all-platform competitor (MIT, YC-backed, 27k stars); see [Orca Competitor Analysis](./43-orca-competitor-analysis.md)

These references are used for architecture study, UI comparison, PTY/session management ideas, and workflow design. They are not part of the product source tree and should not be treated as build inputs.
