# 17. AI 面板：让 AI 给你画一块界面

> 终端里的 AI 只能吐字符——想给你看一张对比表，它只能拿 `|---|` 拼；想问你选 A 还是 B，它只能让你自己敲字回答。
> **AI 面板**给它开了另一条路：AI 可以直接渲染一块真正的界面给你看，界面上的按钮你点了，它那边收得到。

## 它和终端标签有什么区别

| | 终端标签 | AI 面板 |
| --- | --- | --- |
| 内容 | AI 进程的实时输出流 | AI 主动投递的一块 HTML 或 Markdown |
| 谁决定长什么样 | 终端 / CLI 自己 | AI 每次投递时决定 |
| 你怎么回应 | 敲字，回车 | 点面板里的按钮（HTML 面板） |
| 生命周期 | 跟着进程活 | 会话关了内容还在，进历史 |
| 位置 | 主编辑区的标签页 | 右侧坞的一个视图，或一个居中弹框 |

关键差别是：**终端是流，面板是一块可以整体替换的画布**。AI 可以反复更新同一块面板（比如把进度条从 30% 刷到 80%），而不是在终端里刷一屏又一屏。

## 什么时候用得上

- **让 AI 给结论配一张表**：多方案对比、依赖体检、跨仓库改动清单——比终端里的纯文本表好读。
- **AI 要你拍板**：它渲染几个按钮（"用方案 A" / "用方案 B" / "都不要"），你点一下，它拉到事件继续干。
- **长任务的进度看板**：派了 5 个 worker 出去，让指挥实例把总览刷在面板上，你扫一眼就知道谁卡了。
- **一次性的富文本汇报**：调查报告、评审意见，Markdown 面板比塞在终端滚动区里更容易回头找。

## 怎么打开

AI 面板默认放在**右侧坞**。三种打开方式：

1. **点右侧坞顶部的 AI 面板图标**（一排视图切换按钮里的一个）。图标右上角有**琥珀色小圆点**时，表示有你还没看过的面板。
2. **命令面板**：`Ctrl+K` → 搜"AI 面板" → 「打开 AI 面板」。注意从命令面板打开时，面板是以**居中弹框**形式出现的，不是进右侧坞。
   > ⚠️ `Ctrl+K` 在**终端处于聚焦状态时不生效**——这个键被放行给终端了（终端里 `Ctrl+K` 是 kill-line，Claude Code 也常用）。先点一下终端以外的地方，再按。
3. **AI 主动推给你**。默认情况下它不会自己弹出来，只会标个未读点；要不要让它弹，见下面的设置。

## AI 是怎么往里投递内容的

CC-Panes 把面板做成了一组 MCP 工具，跑在里面的 Claude / Codex 直接就能调（不用你配，见 [用 MCP 让 AI 自己操控 CC-Panes](mcp-orchestration.md)）：

| 工具 | 干什么 |
| --- | --- |
| `open_ai_panel` | 开一块新面板，给标题、格式（`html` / `markdown`）和正文 |
| `update_ai_panel` | 整块替换自己那块面板的内容（用来刷新进度、改结论） |
| `close_ai_panel` | 关掉面板。**内容不会丢**，只是离开活跃集、进历史 |
| `get_ai_panel_events` | 拉取你在面板上点了哪些按钮 |
| `list_ai_panel_history` | 翻历史面板，找回以前开过的那块 |
| `claim_ai_panel` | 认领一块没人持有的历史面板，接着往下用 |

几条你需要知道的规矩：

- **面板归开它的那个会话所有**。别的会话不能改你这块面板——想接手，得等原主 `close` 或退出后，再 `claim_ai_panel` 认领。
- **两种格式**：`markdown` 走 CC-Panes 自己的 Markdown 渲染（好读，但**没有按钮**）；`html` 走一个沙箱 iframe，可以放按钮、做交互，按钮上写 `data-action` 才会把点击回传给 AI。
- **单块面板正文上限 256 KB**，标题上限 512 字节。超了 AI 会收到报错，得自己精简。
- **AI 调用成功 ≠ 你看见了**。工具返回值里带一个 `delivery` 字段，告诉 AI 这次到底是弹框了（`dialog`）、进右侧坞了（`dock`）、只标了未读（`unread`），还是被你关死了（`disabled`）。写得好的 skill 会读这个字段再向你描述，而不是一律说"已弹出"。

## 面板历史

面板不是"当下这一个"，而是一份可回溯的记录。打开 AI 面板时，**默认落点就是历史列表**，按**工作空间**分组，每条显示标题、驱动它的 AI 名字、更新时间和正文大小。

- 点任意一条即可查看正文；左上角返回箭头回列表。
- 还有会话持在手里的面板，标题旁有一个**绿色小图标**（"仍在活跃"）。
- 没有会话持有的面板，打开后标题旁挂一个 **「已归档」** 标签——它是**快照**，上面的按钮点了不会有任何反应。想继续交互，得让某个 AI 去 `claim_ai_panel` 认领它。
- **历史不会自动清理**。要删只能手动：把鼠标移到列表里那一条上，点右边的垃圾桶图标。

## 设置：控制它能打扰你到什么程度

**设置 → 模块 → AI 面板**（模块页在"外观与交互"分组下）。这里有四个旋钮：

| 设置项 | 默认值 | 说明 |
| --- | --- | --- |
| 启用开关 | 开 | 关掉后面板数据照样存，但界面上**没有任何入口** |
| 位置 | 右侧坞 | 可选「右侧坞」或「隐藏」。隐藏后仍可从命令面板打开 |
| 收到更新时自动打开 | **关** | 开了之后，AI 一投递就自动把面板亮到你面前 |
| 允许 AI 请求弹出面板 | **开** | AI 可以显式要求"这次必须弹框"，盖过上面那条 |

这两个开关的组合逻辑是：

- 两个都是默认值（自动打开=关、允许请求=开）→ 平时只标未读，但 AI 认为重要时能弹给你。
- 被弹烦了 → 关掉「允许 AI 请求弹出面板」，从此**一律只标未读**，你自己什么时候想看什么时候看。
- 想全程盯着 → 打开「收到更新时自动打开」，每次投递都自动亮出来。

## 常见问题

**面板上的按钮点了没反应？**
先看标题旁有没有 **「已归档」** 标签。有 = 这是快照，当前没有会话持有它，点击无处可去。让 AI 调 `claim_ai_panel` 认领后即可继续。

**AI 说它"弹了个面板"，可我啥也没看见？**
多半是你的「收到更新时自动打开」是关的（默认就是关的），面板只是被标成了未读。去右侧坞看那个带琥珀点的图标。如果连图标都没有，检查设置里 AI 面板的启用开关和位置是不是被设成了「隐藏」。

**面板不见了，内容还找得回来吗？**
找得回。`close` 只是让面板离开活跃集，正文仍在历史里，按工作空间分组。**只有你手动点垃圾桶才会真删。**

**为什么有的面板能点按钮，有的只能看？**
Markdown 格式的面板只做渲染，不带交互桥；HTML 格式的才能收按钮事件。这是 AI 在投递时选的，不是你能切换的。

**另一个实例开的面板，我这边能改吗？**
不能。面板有归属，跨会话操作会被直接拒绝。要接手，先让对方关掉或等它退出，再认领。
