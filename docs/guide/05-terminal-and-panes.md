# 5. 终端与分屏

CC-Panes 的中央工作区由**标签页**和**分屏面板**组成，外面再套一层**布局**。把这套玩熟，多任务并行就很顺手。

## 标签页

每个面板顶部是一条标签栏，每个标签是一个终端（或文件、Diff、预览）。

- **新建标签**：点标签栏的 **`+`**，或按 **`Ctrl+T`**。
- **切换标签**：点标签；或用 **`Ctrl+Tab`**（下一个）/ **`Ctrl+Shift+Tab`**（上一个）；或 **`Ctrl+1` ~ `Ctrl+9`** 直接跳到第 N 个。
- **关闭标签**：**`Ctrl+W`**，或标签右键 →「关闭标签」。

### 标签右键菜单

在标签上右键，常用动作：

| 菜单项 | 作用 |
| --- | --- |
| 重命名 | 给标签改个好认的名字 |
| 固定标签 / 取消固定 | 固定后不会被"关闭其他"误关 |
| 最小化 | 收起标签 |
| 终端 · 右切 / 终端 · 下切 | 把当前终端向右 / 向下分屏 |
| 关闭左侧 / 右侧 / 其他标签 | 批量清理 |
| 恢复已关闭标签 | 误关了找回来 |
| 在文件树中显示 | 定位该标签对应的目录 |
| 弹出为独立窗口 | 把标签拆成独立窗口（多屏幕好用），关掉后自动回收 |

## 分屏

让多个终端并排，一边看 AI 跑、一边自己敲命令：

- **向右分屏**：标签右键「终端 · 右切」，或 **`Ctrl+\`**。
- **向下分屏**：标签右键「终端 · 下切」，或 **`Ctrl+-`**。
- **调整大小**：拖动面板之间的分隔线。
- **面板间切换焦点**：**`Alt+方向键`**（左 / 右 / 上 / 下）。

## 布局（LayoutBar）

ActivityBar **最顶部**是布局切换条。一个**布局**就是一整套分屏 + 标签的排布，你可以为不同场景存多套，一键切换：

- **新建布局** / **重命名布局** / **删除布局**（均在布局条上操作，也可在布局卡片右键菜单里取用）。
- 删除布局时，该布局里仍在运行的终端会话和弹出窗口会一并关闭，所以会让你确认。
- 至少保留一个布局，**最后一个布局不可删除**。

### 两种摆放位置

布局切换器有两种形态，可随时互切：

- **左下角浮窗**（corner，默认）— ActivityBar 底部的命令图标，悬停展开列表。
- **顶部布局条**（topbar）— 横在终端标签上方，每个布局是一张卡片。

浮窗右上角的按钮切到顶部布局条，布局条右端的按钮切回来。布局条还有**舒适 / 紧凑**两档密度（右键菜单或右端按钮切换）。

### 布局卡片上的信息

舒适档的卡片有三行：

1. **布局名** + 该布局的标签总数。
2. **绑定的工作空间** + **会话状态**。带链条图标 = 你右键手动绑定的；名字后带 `?` = 按标签内容自动推导的。
   状态按四类分桶，**形状和颜色同时区分**（灰度截图或色觉差异下也能读）：
   实心三角 = 出错、实心菱形 = 等你授权、实心圆 = 正在干活、空心圆 = 空闲。数量为 0 的类别不显示。
3. **内容类型计数** — 终端 / 浏览器 / 文件 / 工具面板各有多少个。
   **点一下就跳过去**，再点一下轮到该类的下一个；不会隐藏其他标签。

### 绑定工作空间

在布局卡片（或浮窗里的行）上右键 →「绑定工作空间…」，之后从该工作空间发起的启动会优先落到这个布局。已绑定的可以「解除绑定」，解除后回到按标签自动推导。

## 新建标签：不只是终端

标签栏右端的 **＋** 左键直接开一个新终端；点它**右侧的小箭头**可以选择：

- **新建终端**
- **新建浏览器** — 打开一个内置浏览器标签，在地址栏输入网址即可
- **打开文件…** — 选一个文件，在当前窗格里打开编辑器
- **打开目录树** — 在当前窗格里开一个文件树

浏览器标签右键可**复制链接**，文件标签右键可**复制文件路径**、**在文件树中显示**。

## 终端状态怎么看

终端启动 / 恢复时，标签和工作区会给出状态提示，常见的有：

- **准备就绪** — 可以用了
- **正在启动终端** — 正在拉起会话，稍等
- **正在恢复会话** — 应用重启后在续上次的标签
- **恢复失败** — 看终端输出排查原因

## 常用快捷键速查

以下是默认值（都可在 **设置 → 快捷键** 里自定义）：

| 快捷键 | 动作 |
| --- | --- |
| `Ctrl+T` | 新建标签 |
| `Ctrl+W` | 关闭标签 |
| `Ctrl+\` | 向右分屏 |
| `Ctrl+-` | 向下分屏 |
| `Alt+←/→/↑/↓` | 切换到左 / 右 / 上 / 下面板 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 下一个 / 上一个标签 |
| `Ctrl+1` ~ `Ctrl+9` | 切换到第 1~9 个标签 |
| `Ctrl+B` | 折叠 / 展开侧边栏 |
| `F11` | 切换全屏 |
| `Ctrl+M` | 切换迷你模式 |
| `Ctrl+,` | 打开设置 |
| `Ctrl+Alt+M` | 语音输入 |

### 为什么我在终端里按 `Ctrl+W` 没关标签？

这是**有意为之**。当焦点在终端里时，少数与 CLI / 终端本身冲突的快捷键（如 `Ctrl+B`、`Ctrl+T`、`Ctrl+W`、`Ctrl+M`、`Ctrl+\`、`Ctrl+-`）会**放行给终端**，让 Claude Code 等程序自己处理。想用这些 App 级动作时，先把焦点点到终端外，或改用标签右键菜单。
