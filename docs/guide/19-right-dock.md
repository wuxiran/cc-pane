# 19. 右侧坞：把 Git、文件、AI 面板、会话历史收在右边

> 终端占着屏幕中间，左边被工作空间树占着。那些「每隔几分钟就想瞟一眼、但不值得为它开一个标签页」的东西——AI 到底改了哪几个文件、它往面板里投了什么、上周那个会话叫什么——放哪儿？放右侧坞。

## 什么时候用得上

- 让 Claude 在终端里改代码，你在右边**实时看它改了哪些文件**，改一个多一个
- 想快速点开某个文件，但不想为此把左侧栏从当前视图切走
- 派了 AI 出去干活，想瞟一眼它往 [AI 面板](17-ai-panel.md) 投递了什么
- 想 resume 几天前那个会话，但记不清是哪个项目的

右侧坞和左侧栏可以**同时开着**，互不干扰。

## 怎么打开

标题栏最右边、齿轮（设置）按钮的**左边**，有一个「面板」形状的图标按钮：

1. 点它 → 右侧坞展开（悬停时提示文字是「展开右侧面板」）
2. 再点一次 → 收起（此时提示变成「折叠右侧面板」）
3. 拖右侧坞**左边缘的分隔条**可以改宽度，范围 280–560 像素，默认 340
4. 在这条分隔条上**双击**，也能直接收起

有两件事最好现在就知道：

- **右侧坞没有快捷键。** CC-Panes 的快捷键体系里压根没注册「切换右侧坞」这个动作——所以设置 → 快捷键里找不到它，命令面板里也搜不到。只能点标题栏那个按钮。
- **每次重启，右侧坞都是收起的。** 宽度和你上次停在哪个页签会记住，但「开着」这个状态是刻意不保存的。

## 里面有什么

顶部一排小图标就是页签。其中两个是**内置的、永远在**，剩下的是**可以搬进来的模块**。

### 文件（内置）

当前工作空间下的**每个项目各一个可折叠的根节点**（IDEA 多模块那种感觉），你选中的那个项目默认展开，其余折叠。折叠着的项目不会去读磁盘，所以工作空间里塞几十个项目也不卡。

### Git（内置）

同样是每个项目一行，一眼看到：

- 当前**分支名**
- **变更文件数**（右边那个小数字）
- 展开后是**变更文件列表**，前面一个字母标着状态（新增 / 修改 / 删除等），删除的文件会加删除线
- 点任意一个变更文件 → 打开该文件的内容对比
- 鼠标悬停在项目行上，右边会浮出两个小按钮：**打开 Git 时间线** 和 **刷新**

项目不是 Git 仓库、或者路径已经不存在了，这里会直接写出来（「非 Git 项目」「项目路径不存在」「Git 不可用」），不会假装在加载。

### 可以搬进来的模块

**AI 面板** 和 **会话历史** 默认就在右侧坞。**SSH 机器** 默认在左侧活动栏，可以搬过来。

搬法有两条路，效果一样：

- 在**左侧活动栏的图标条上右键** → 「模块位置」 → 选中模块 → 「移到右侧」
- **设置 → 模块** → 找到该模块 → 位置选「右侧坞」

同一个菜单里还能把模块整个「隐藏」——隐藏后入口消失，但仍可以从命令面板打开。

**会话历史**这个页签值得单独说一句：它列出本机所有历史会话，可以按「全部 / 当前工作空间 / 当前项目」缩范围、按 CLI 类型筛选、搜关键词，每条显示消息数和摘要，点「恢复」就地接回去。Codex 的会话文件如果已经被清掉了，它会明确告诉你「Codex 会话文件已不存在，无法恢复」，而不是让你点了没反应。

> 标题栏那个开关按钮右上角如果有个**琥珀色小圆点**，表示 AI 面板有未读内容。

## 和左侧栏是什么关系

一句话：**左边是导航，右边是旁观。**

| | 左侧栏（活动栏 + 侧栏） | 右侧坞 |
|---|---|---|
| 干什么 | 找东西、进东西：工作空间/项目树、会话列表、文件浏览器、SSH、编排 | 盯东西：当前项目的 Git 变更、文件树、AI 面板、会话历史 |
| 折叠 | `Ctrl+B`（默认） | 只有标题栏按钮 |
| 重启后 | 记住展开状态 | 总是收起 |

右侧坞盯的是**哪个项目**？按这个顺序找：你在左侧栏里展开/选中的项目 → 展开的工作空间 → 当前活跃终端所属的项目 → 第一个有项目的工作空间。所以你在左边点谁，右边就跟着谁。

## 一个已知的坑：三个视图切换动作绑不了快捷键

CC-Panes 内部注册了三个切换左侧栏视图的动作——`show-explorer`（资源管理器）、`show-sessions`（会话）、`show-files`（文件浏览器）。它们**没有默认快捷键**。

而「设置 → 快捷键」这个页面，只列出**已经有绑定的**动作。这三个既然一开始就没绑定，它们在这个页面里**完全不出现**——你看不到它们，也就没法给它们绑键。这不是找不到入口，是当前版本确实做不到。

所以唯一的触发方式是**命令面板**：

1. 按 `Ctrl+K` 打开命令面板
2. 输入 `Explorer` / `Sessions` / `Files`（这三条的标签是英文硬编码的，输中文搜不到）
3. 回车

还有一层：`Ctrl+K` 本身在**终端聚焦时会被放行给终端**（它是 readline 的 kill-line、也是 Claude Code 的常用键，抢过来会打断你敲命令）。所以如果你正在终端里打字，`Ctrl+K` 不会开命令面板——先点一下终端以外的地方（比如左侧栏空白处），再按。其它同样会被放行给终端的快捷键，见 [附录 B：快捷键速查](appendix-b-shortcuts.md)。

## 常见问题

- **右侧坞打开是空的，写着「工作空间中没有项目」？** 右侧坞展示的是当前工作空间下的项目，先在左侧栏往工作空间里加项目（见 [03. 核心概念](03-core-concepts.md)）。
- **切了页签内容没变 / 显示的是别的项目？** 右侧坞跟随的是「当前项目」，在左侧栏里点一下你想看的那个项目即可。
- **把 AI 面板或会话历史「隐藏」了，怎么找回来？** 设置 → 模块，把位置改回「右侧坞」；或者直接 `Ctrl+K` 命令面板搜「打开 AI 面板」/「打开 会话历史」。
- **把 TodoList / 任务编排 / 资源中心「移到右侧」了，图标出现在右侧坞里，但点了却是全屏打开？** 这三个模块只有**入口**能挪位置，视图本身仍是全屏或浮层——右侧坞里不会渲染它们的内容。想要真正待在右侧坞里的，目前是文件、Git、AI 面板、会话历史、SSH 机器。
- **右侧坞拖不宽了？** 上限就是 560 像素。需要更大的阅读区域，用文件标签页或编辑器（见 [06. 文件浏览与编辑](06-files-and-editor.md)）。
