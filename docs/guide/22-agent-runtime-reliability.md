# 22. Agent 运行记录、验收与整轮恢复

CC-Panes 分别记录执行过程、检查证据和人工验收。Agent 回复结束后，可以继续查看过程、运行检查，再决定是否验收或恢复本轮文件。

## 四项功能的入口

| 功能 | 入口 |
|---|---|
| 运行记录 | Agent 聊天顶部的「运行记录」按钮或更多菜单；尚未启动引擎的选择页也有入口 |
| 完成验收 | 编排任务详情中的「完成与验收」和「验收证据」区域 |
| Mac 浏览器操作 | 通过 MCP 打开应用内浏览器标签，再调用 `browser_evaluate`、`browser_click`、`browser_screenshot`，见[浏览器标签说明](20-browser-tab.md) |
| 整轮检查点 | 聊天顶部或引擎选择页的「整轮检查点」；运行记录中的「查看此回合检查点」可定位历史聊天对应的检查点 |

## 查看保存的执行过程

「运行记录」支持按当前标签、当前引擎会话或全部记录查看，也可输入引擎 ID、会话 ID 筛选。运行列表和事件内容分别分页，不会为了查看历史而启动 Agent。

记录包含已接收回合的用户输入、流式正文、工具事件、问题、权限请求和结束状态。历史问题与权限请求仅供查阅，不能在这里重新回答或批准；查看记录也不会恢复旧审批到当前聊天。

| 运行状态 | 含义 |
|---|---|
| 运行中 | 尚未保存本轮结束记录 |
| Agent 已结束 | 引擎已结束本轮，不代表检查通过或用户验收 |
| 已取消 | 本轮已完成取消收尾 |
| 失败 | 本轮执行失败 |
| 已中断 | 执行或应用关闭时未正常完成本轮，例如重启后发现未结束记录 |

若保存过程出现错误或缓冲区超限，界面会提示「记录不完整」。图片原始数据保留在记录中，历史预览省略图片编码；超长文本也会明确标注预览截断。

持久记录覆盖**后端已接收的 ACP 回合**。尚未发送的草稿、引擎启动或握手失败前的输入不在此范围内。要继续工作，仍需通过原有会话续接入口启动支持续接的引擎；本地记录用于查看已发生的过程，不保证恢复商业引擎内部状态。

## 配置完成条件并验收

在任务详情填写文字完成标准，以及每行一条的必需检查命令，保存后按需运行检查。保存条件本身不会执行命令；文字标准由用户审阅确认。

三个阶段独立显示：

1. **Agent 已结束**：编排任务的执行状态为 `completed`。
2. **检查通过**：每条必需命令的最新一次执行成功，且证据仍对应当前代码。失败、超时、检查期间代码变化或无法确认代码状态，都不能算通过。
3. **用户验收**：用户审阅后点击「验收当前结果」。后端重新核对任务和条件版本、代码指纹及已查看的证据 ID，防止旧页面验收后来变化的结果。

改变完成条件会清除之前的验收；任务结果、代码或检查证据变化后，旧验收不再适用。没有配置检查命令时，可以明确进行人工验收，但不会因此显示「检查通过」。Worker 报告完成或修改普通任务元数据，也不会自动生成验收通过状态。

## 整轮检查点的范围

每轮开始和结束时保存工作区文件快照。恢复目标是**本轮开始前的内容**，包含当时已有的未提交修改。前后快照也可能包含同仓库其他进程造成的变化，因此恢复前应查看实际文件清单。

捕获范围为已跟踪文件，以及未被忽略的未跟踪文件；新建的忽略文件和仓库外路径不包含在内。上限为 20,000 个文件、单文件 32 MiB、总计 256 MiB；超限或捕获失败会明确标记检查点不可用。列表默认展示最近 200 轮，历史运行中的检查点链接可直接定位更早记录。

恢复前需要勾选已审阅确认。以下情况会阻止整轮恢复：

- 同仓库有活动回合或仍在运行的托管后台命令；本轮结束时后台命令尚未停止的检查点也会标记不可恢复。
- 缺少有效的前后快照，包括中断后未保存结束快照。
- 本轮改动的文件存在后续编辑，或仓库 HEAD 已变化。
- 涉及符号链接、不支持的文件模式、已恢复的检查点，或没有可恢复的文件变化。

恢复会保留无关文件，并在写入前重新检查当前状态。恢复前的文件快照另外保存用于找回内容。此操作只恢复工作区文件，不撤销 Git 提交、暂存区、已执行命令、数据库或外部服务上的操作。

## macOS 浏览器能力

应用内浏览器在 macOS 使用 WKWebView 原生脚本、鼠标事件和视图快照。点击坐标使用页面可视区域的逻辑 CSS 像素；网页截图只包含当前可视区域，不需要系统屏幕录制权限。系统区域截图是另一条功能路径。

`browser_evaluate` 要求 **macOS 11 或更新系统**，旧系统会返回明确错误。表达式、Promise 和普通同步语句可以返回结果；异步多语句建议写为 `(async () => { /* 操作 */ return result; })()`。未完成的 Promise 在 10 秒后超时，JavaScript 异常通过 `exceptionDetails` 返回，结果大小上限为 64 KiB。

隐藏或最小化窗口时，网页截图可能超时，可恢复窗口可见后重试。视频、WebGL 等 GPU 图层取决于系统 WebKit 的快照表现。Linux 暂不支持这三项操作；Windows 的 WebView2 路径保持独立，Mac 验证不能替代 Windows 主机验收。

## 存储与开发验证

正式版数据目录为 `~/.cc-panes/`，开发版为 `~/.cc-panes-dev/`：

- `agent-chats/runtime-records/runs.sqlite3`：运行及事件记录；单独的 writer 持有独占锁，关闭确认在数据库和锁真正释放后返回。
- `data.db` 的 `task_completion` 表：完成条件及人工验收记录，数据库迁移版本 44。
- `task-verification/`：独立检查证据；`turn-checkpoints/`：整轮检查点记录，文件内容由仓库快照存储保存。

在仓库根目录完成依赖安装后，可运行以下检查。两个 example 需要本机图形会话；浏览器 example 仅限 macOS，ACP example 当前使用 Unix、Git 和 Python 3。

```sh
cargo test -p cc-panes-core --test task_verification --test turn_checkpoints
cargo test -p cc-panes --lib services::acp_chat_service::journal::tests
node --test scripts/browser-macos-evaluate.test.mjs

cargo run -p cc-panes --example browser_macos_smoke -- /tmp/cc-panes-browser-evidence
cargo run -p cc-panes --example agent_runtime_smoke -- /tmp/cc-panes-runtime-evidence
```

浏览器示例操作自建本地测试网页并检查实际 WKWebView 输出。ACP 示例通过真实应用服务和传输链路运行本地 **owned fake adapter**，验证记录、取消收尾、后台命令、检查点恢复和离线重开；它不调用真实商业引擎，也不能证明某个商业引擎的登录、模型或续接兼容性。两个示例使用自建测试环境，并把 JSON 验收结果写入指定目录。
