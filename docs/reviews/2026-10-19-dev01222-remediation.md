## 数据与运行时变化

数据库迁移 41 将旧台账的两个命令文本字段替换为隐私占位文本。这些旧文本可能已泄漏完整或部分凭据，无法可靠恢复原始引号边界。迁移保留记录、会话关联、时间、退出码和资源指标；旧命令文本不会保留备份。该迁移尚未对当前运行应用的真实数据库执行。

WSL 使用 `bash "$CC_PANES_RUN" --heavy -- <command>`；本机 POSIX 使用 `"$CC_PANES_CTL" run --heavy -- <command>`，PowerShell 使用 `& $env:CC_PANES_CTL run --heavy -- <command>`。没有重写会话 PATH。

设置内容和资源管理器详情改为按需加载，入口 gzip 降至 878.4 kB，满足现有 880 kB 预算。预算未放宽。四个侧车已重建，复制到工作目录资源和 debug 运行时目录，并校验哈希一致。
