# CC-Panes 宠物模块审阅与修复

本轮针对 CC 酱的显示、窗口交互、设置、角色资源和聊天生命周期修复，基于 `e8e71f7e`，位于 `codex/fix-dev01222-audit` 分支。修复将窗口尺寸交由同一条串行更新链处理，并让聊天进程的生命周期与所属会话一致。

## 修复范围

| 范围 | 故障与修复后的行为 |
| --- | --- |
| 精灵显示 | 内置图集单帧为 192×208，原按宽度缩放会超出正方形窗口；现在完整缩放并居中。 |
| 拖动 | 物理窗口坐标与 DOM 逻辑坐标混用导致高 DPI 位移不准；现在统一换算，合并过时移动请求，按松手坐标保存最终位置。取消手势后不会执行迟到的定位请求，拖动后的 click 不再误开聊天。 |
| 漫游 | 拖动、聊天、菜单和气泡显示期间暂停漫游；异步查询返回后重新检查取消状态。 |
| 窗口布局 | 展开窗口按显示器工作区限制大小和位置，收起时恢复宠物锚点；小屏幕上的聊天面板随实际窗口尺寸缩小。 |
| 右键菜单 | 菜单关闭或转入聊天后，迟到的 resize 响应不再把菜单重新打开。 |
| 外部气泡 | 去掉直接修改 DOM 和独立缩窗定时器的路径，统一由 React 状态管理；启动期间的消息暂存，监听器注册成功后领取，旧气泡不会把聊天窗口缩小。 |
| 设置保存 | 右键换角色持久化；部分设置更新保留其他字段；迟到的初始加载不会覆盖较新的设置事件。后端单独更新宠物设置时持锁保存，避免拖动覆盖其他全局设置。 |
| 显示与启动 | 设置中的可见性和位置重置应用到原生窗口；启动遵守自动显示配置。显式关闭同步主窗口状态，应用退出时保留显示偏好。 |
| 主窗口操作 | 接通宠物菜单的设置入口及会话圆点跳转，并通过专用后端命令唤起主窗口，不依赖未授权的前端 focus 权限。 |
| 角色资源 | 刷新资源广播给宠物窗口；单个损坏的内置角色不会挡住其他角色和自定义角色；拒绝帧数与列偏移越出图集边界。 |
| 收起聊天 | 首次展开后保留聊天组件，收起时继续接收回复并保留草稿，隐藏内容不可聚焦。 |
| 聊天生命周期 | 停止、隐藏和替换会话会终止所属 CLI 进程树；拒绝同一会话的重叠发送；取消启动后回收迟到的会话；旧发送失败不会清空新会话。切换引擎替换实际会话，续接 ID 在放行下一轮前更新。 |
| 中文输入 | 输入法组合期间的 Enter 只确认输入，不发送消息。 |
| 监听与动画 | 异步监听注册若晚于卸载完成，立即注销；单帧角色、隐藏页面及减少动态效果模式不持续运行动画循环。 |

窗口布局、进程管理、拖动、漫游和消息格式分别拆为独立模块。宠物主组件从 984 行缩至 524 行，聊天面板从约 1000 行缩至 712 行。
