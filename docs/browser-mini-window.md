# 浏览器小窗

浏览器工具条的“小窗查看”把当前活网页移入右上角约 480×300 的置顶窗口。可以拖动、调整大小，或恢复为常规浏览器窗口。小窗里的“回到主面板”和关闭按钮都会收回网页；原标签不删除。

小窗与普通弹窗共用同一个原生 WebView，切换不会重新导航。主界面切换标签后，小窗仍保留；原标签显示小窗状态及召回入口。登录 Cookie、表单值、页面脚本与会话存储随原页面保留。

小窗使用紧凑控制条，地址栏、批注与 Computer Use 工具保留在常规窗口。响应式预览在小窗内暂时停用，恢复常规窗口后可继续使用。小窗与 Codex 派工功能独立，不连接或控制 Codex 客户端的悬浮预览。

macOS 原生验收覆盖右上角工作区定位、480×300、置顶、无原生标题栏、可调整大小、mini／window／主面板切换及页面状态保留。Windows/Linux 原生窗口行为需各自在实机验证。
