# 统一内容工作台

## 与参考界面的差距

CC-Panes 原本已有多种内容查看器：网页、终端、Agent Chat、代码编辑器、Markdown 编辑／预览／双栏、常见栅格图片缩放及目录树。主要差距在入口、混排规则和浏览器工具，而非缺少整个大面板。

| 能力 | 此次状态 |
| --- | --- |
| 网页、Markdown、图片、代码、终端共用面板 | 复用现有查看器，补齐统一新标签页入口 |
| Agent 工作台混排 | 可保留 browser、terminal、editor、review 等标签，切换／恢复不再迁走网页 |
| 常驻变更页 | 上一轮／工作区／分支审阅可作为标签保留 |
| 新标签页工具首页 | 已加入地址输入、变更、终端、打开文件、新建 Markdown、Agent、目录入口 |
| 标签外观 | 主题适配的圆角高亮、内容图标、固定新建与分屏工具区 |
| 常用标签操作 | 右侧新建、网页复制、重载、URL 复制、外部打开、持久命名、左右面板移动、原有关闭保护 |
| 网页图标 | 提取有上限的同源栅格图标；不支持的图标安全回退 |
| 响应式预览 | 原生尺寸／缩放、设备预设、旋转、自动适应、拖柄和方向键；显示实测 CSS 视口 |
| 网页独立窗口 | 移动原生 WebView，保留页面状态；关闭浮窗会回收至原面板 |
| 网页批注 | 定格截图框选、编号与文字、PNG 与 JSON 元数据、图片／引用复制、Agent 草稿 |
| 原生标签静音 | 尚未实现；没有用 DOM media.muted 冒充整页静音 |
| 置顶到侧栏 | 尚未实现；既有“固定标签”和“星标布局”语义保持独立 |
| PDF、音视频、Office、通用文档独立窗口 | 本轮未新增；不能将代码／二进制显示称为对应格式预览 |

## 使用

点击标签栏固定位置的 `+` 打开工具首页，或从旁边的下拉菜单直接选择内容。网址提交后才创建原生网页视图；空白新页不会发出外部页面请求。打开文件时，目标保持在发起操作的面板；没有项目路径时从所选文件推导目录。

“新建页面”创建空白 Markdown 文件。通过原生保存对话框选择位置，底层使用原子创建，已有文件及符号链接不会被覆盖。文件随后在原面板打开，仍使用原有未保存内容保护。

网页标签右键可复制为一个重新加载当前 URL 的独立标签。此操作不复制 CLI 进程、Agent 会话或编辑器的未保存缓冲；会话分叉仍走原有协议。网页手动名称与页面标题分开存储，后续标题事件不会覆盖用户命名。

## 响应式与浮窗

从网页工具栏进入响应式预览。目标宽高属于 CSS 视口，缩放表示在宿主中的显示比例；页面实际 `innerWidth`／`innerHeight` 会读回显示。实现使用原生视图尺寸与 page zoom，并根据实测滚动条占用做有界补偿，没有用外层 CSS transform 假装改变网页视口。

尺寸与缩放变更会使旧 Computer Use 快照失效。失败、取消或超出宿主范围时恢复原生视口状态。macOS fixture 已验证 1440×1000 @57%、1000×1440 @45%、media query 和缩放后的可信点击；Windows 仍需独立实机验收。

“移至新窗口”转移同一原生 WebView，并由后端仲裁宿主。浮窗关闭时先回收页面，再销毁宿主窗口；主布局暂时卸载不会关闭已弹出的网页。真正关闭标签仍使用统一生命周期清理。

## 批注

“批注”先定格当前页面截图，校验捕获前后的文档身份、URL 与视口。拖动框选区域后填写编号说明；此时操作的是图片，不会点击真实页面。

导出的 PNG 含区域、编号和文字说明，并另存 JSON，保留来源、捕获时间、CSS 视口与图像坐标。复制引用可用于 CLI 会话；主窗口中可将图片与说明加入已启动 Agent 会话的草稿，不会自动发送。浮窗没有共享会话草稿列表时可复制后回到会话粘贴。

若目标会话在图片读取期间关闭或换了 ACP session，交接会拒绝完成，不复活旧草稿。关闭尚未保存的批注会请求确认；导出失败会显示错误，不报告成功。

## 边界

- 现有网页工具仍操作内置浏览器顶层文档，不控制其他桌面应用。
- 网站图标仅接受受限栅格格式，同源请求限时、限大小；SVG、跨站图标和失败请求使用类型图标回退。
- 浮窗这一轮针对浏览器内容；文件与 Agent 的通用独立窗口没有被宣称完成。
- UI 组件预览与原生浏览器验收分别记录，不能将演示数据预览等同于完整桌面端到端测试。
