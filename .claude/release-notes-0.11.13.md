## 新增（Added）

- **异常退出后的会话冷恢复。** 应用异常退出后对着不支持安全认领的旧守护进程，被拦的终端过去只有死路。现在分情况处理：本进程内的活会话直接重连；确证已死的静默恢复；只有「旧 daemon 上还活着」的才保持拦截——并给出「结束旧终端并恢复」按钮（先杀旧、成功后才建新）。fail-closed 身份校验未放松，新增恢复事件已进中文日志。
- **每终端独立状态栏。** 多分屏布局下每个终端底部一条状态栏：会话状态 / CLI / 模型 / 推理档 / 上下文用量 / 项目路径（右键可隐藏；单分屏不显示）。上下文用量改为**按终端独立跟踪**，不再被聚焦终端覆盖所有人的数字；会话退出即清缓存并有上限兜底。终端设置新增两个开关。
- **上下文窗口终于跟着你的 Provider 走。** Provider 模型可声明上下文窗口（编辑器带常用容量预设）；用量指示器优先用转录实测窗口，其次 Provider 配置，都没有时显示用量但不显示百分比（而非报错）。Claude 硬编码 200k 的假设移除。启动历史按次记录模型（migration v30）。
- **复制 Provider 走新建**，不再静默改原 Provider，每次保存生成新 id。
- **Claude 托管 Provider 经每会话 `--settings` 文件注入环境**——凭据不再过 CLI 参数，你自己的 `~/.claude.json` 依旧只读。两个行为待实测反馈：空串重置语义、subagent 模型钉定（docs/82 §8）。
- **多主题预设**：多套内置主题 + 实时预览 + 壁纸预览面板，状态栏主题按钮变菜单，旧的亮/暗选择平滑迁移。
- **终端路径链接**：终端输出里的路径可点击，确认后在编辑器打开；对 URI scheme、控制字符、路径逃逸、远程运行时都做了拒绝。
- **懒加载视图升级后自愈**：升级后旧分片取不到时按标签/设置分区粒度带缓存穿透重试，不再整窗白屏。
- **Windows 绿色免安装版**：从本版起每个 release 自动附带 `cc-panes_<版本>_x64-portable.zip`，解压即用（数据仍在 `~/.cc-panes`，与安装版勿同时运行；升级=下载新 zip 覆盖解压）。

## macOS 安装说明

由于应用未经 Apple 签名，macOS 可能提示"文件已损坏"或"无法验证开发者"。请使用以下任一方式解决：

**方式一：终端命令（推荐）**
```bash
xattr -cr /Applications/CC-Panes.app
```

**方式二：右键打开**
在 Finder 中按住 Control 键点击（或右键点击）应用图标，选择"打开"，在弹出的对话框中点击"打开"。

**方式三：系统设置**
打开"系统设置 → 隐私与安全性"，在底部找到被阻止的应用，点击"仍要打开"。

## Linux 安装说明

**Deb 包（Ubuntu/Debian）：**
```bash
sudo dpkg -i cc-panes_*.deb
sudo apt-get install -f  # 安装缺少的依赖
```

**AppImage：**
```bash
chmod +x cc-panes_*.AppImage
./cc-panes_*.AppImage
```
